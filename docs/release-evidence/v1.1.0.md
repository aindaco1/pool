# Pool v1.1.0 Release Evidence

Generated for branch `release/1.1.0` on 2026-07-12.

## Scope

This release adds variant-specific add-on prices and completes the Store-aligned production quality/admin-operations milestone. It preserves Pool's platform/campaign add-on, pledge, campaign-progress, shipping, reporting, and Worker-authority boundaries. Store-only first-class products, SKUs, tickets/RSVPs, signed downloads, and R2 download-abuse controls remain excluded.
