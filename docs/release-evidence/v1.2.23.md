# Pool v1.2.23 — October 4, 2026

This release includes shared admin image removal, lossless PNG validation,
workflow and browser-fixture repairs, the reviewed dependency updates, and the
creator-guide and Undici updates since v1.2.22. The README, root/Worker packages
and lockfiles, canonical platform version/label, and Worker provider identity
are aligned at 1.2.23.

## Shared adoption and behavior

Platform 0.43.0 is pinned at `e28d2773f3060700f9483a44705038fc436570d1`.
Admin Shell 0.13.0 supplies a reusable removal control, and Media Core 0.5.0
normalizes equivalent framehash aspect ratios. Pool owns localization, field
models, staged-file cleanup, undo, persistence, decoding, and publication.

Every admin image upload field can retain an empty value. Content, Diary,
Blast, gallery slots, and video posters use the same control as scalar fields.
Captions and entries remain editable, late uploads cannot restore removed
images, and empty image elements are omitted from public/protected rendering.
Existing publication cleanup policies and public fallback rules still apply.

## Verification

The [Actions investigation](2026-10-04-actions-and-admin-images.md) inventories
all 72 historical failures and records focused regressions, the complete local
gate, Podman E2E, and the successful feature media pipeline. That pipeline
checked 37 source images and validated 192 image changes plus the manifest;
the exact source image pixels, geometry, timing, and actual aspect ratios remain
protected. Its 29m54s runtime motivated a 45-minute native-repair budget.

The release PR integrates the Ruby action, Wrangler, root development tools,
and paired Vitest/coverage updates. Fresh Merge Smoke and all four dependency
audits verify their combined state. Final commit, deployment, live performance,
cache/crawl checks, and any unavailable provider evidence are recorded in the
GitHub release notes and attached evidence. A submitted workflow is not
production acceptance.

## Deployment and recovery

The Deploy Production workflow deploys Pages and the Worker from the reviewed
immutable commit. The image optimizer independently validates and publishes
image-only changes, then refreshes Pages. No data migration is introduced.
Redeploy v1.2.22 for a full application rollback; preserve current campaign
content and runtime data. For a source rollback of the shared change, revert
the gitlink, media validator and admin adapters, and version-pin assertions
together.

The change adds no messaging, charge, tracking, or permission capability.
Automated test delivery is mocked or disabled; local and hosted tests do not
establish new real payment or recipient-delivery evidence.

Cleanup retains dependency installs, local configuration and secrets, Worker
state, source media/fixtures, immutable tags, and current release evidence.
Generated outputs and superseded branches can be rebuilt or recovered from
Git history or a verified cleanup bundle.
