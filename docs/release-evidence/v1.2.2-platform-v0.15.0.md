## Migration boundaries

Pool consumes the characterized shared HTTP/security response, timezone/date,
Stripe transport, Wrangler inventory, KV transformation, checksum, command
result, and provider-evidence primitives through thin local adapters. Pool
continues to own its default private origin, campaign aliases, Stripe API
version and User-Agent, campaign/pledge/payment rules, routes, storage,
credentials, provider calls, builds, deployment, and rollback.

The Platform submodule contains no Pool credentials, environment IDs, customer
data, campaign content, or deployment authority.
