# Pool v1.2.22 — September 27, 2026

## Scope

This release packages the completed work since v1.2.21 through
`59bfeaae012e0b44d0cf860f95f337bf082bdc6b`: automatic validated image
publication, the pending image optimizations and manifest repair, and the
unassigned-admin-account documentation clarification. Release preparation aligns
the README, root and Worker packages/locks, canonical platform version/label,
and Worker provider identity at `1.2.22`. It also corrects the public-loading
performance failures found during release verification.

Across the consolidated and automatic image commits, 78 responsive WebP files
were added and source images were reduced by 1,056,560 bytes. The optimizer
reports zero pending images. One video derivative remains outside the automatic
image scope; reviewed local video transcoding remains available.

## Performance correction

The initial live three-run Lighthouse medians exceeded the homepage image
ceiling by 30,631 bytes and the Hand Relations third-party ceiling by 590,551
bytes. The 24 first-party images fetched on those routes were unchanged from
v1.2.21. These existing failures were corrected before release; thresholds were
not raised.

- Decorative homepage backgrounds use existing responsive derivatives up to
  640px. Their source files and larger derivatives remain available. Meaningful
  card images keep the full responsive range and use their rendered width with
  a fallback matching the two-column/mobile grid.
- Launch-reminder Turnstile loads on focus, pointer, or input intent. Submission
  still requires a token and the Worker remains authoritative. Failed script
  loads can retry; page load and resizing do not start verification.
- Sixteen focused tests pass, including no token/no submission, concurrent intent,
  successful verified submission, failed script retry, and responsive sizing.
  A mobile Chromium check confirmed zero challenge requests before intent, one
  challenge script afterward, blocked unverified submission, and one mocked
  verified submission. No reminder was sent by this check.
- Final three-run Lighthouse medians, full CI, and deployed acceptance are
  attached to the GitHub release. The earlier incomplete local-server runs are
  diagnostic evidence, not acceptance.

## Release verification and deployment

The release pull request requires a fresh hosted Merge Smoke run and all four
dependency audits after the performance fixes. Additional release-wrapper results and any unavailable
provider or manual evidence are recorded in the release assets and notes.

The production workflow deploys both Pages and the Worker from the exact merged
release commit. The final source revision, CI run, deployment run, public release
label, and live image/crawl checks are recorded in the
[GitHub release](https://github.com/aindaco1/pool/releases/tag/v1.2.22).
A workflow dispatch alone is not deployment acceptance.

Checkout, payment, email delivery, campaign permissions, and data storage are
unchanged. Reminder verification is deferred until intent without bypassing
its existing authorization or anti-abuse checks. Payment/provider delivery and human assistive-technology
acceptance remain separately scoped evidence; simulated checks do not establish
a fresh real purchase or message delivery.

## Ethical review and recovery

Automatic repository writes remain limited to validated image files and
rebuildable metadata. Source content and concurrent creator edits are protected,
full CI precedes publication, and failed gates leave main unchanged. No new
personal-data collection, messaging, financial authority, or campaign access is
introduced.

The removed historical media branches are retained in a verified local Git
bundle. Image commits and the release preparation remain in Git history. For a
production rollback, redeploy the previous known-good commit through Deploy
Production; metadata version changes require no state migration. Preserve local
configuration, dependencies, Worker state, shared submodules, test fixtures, and
release evidence when clearing reproducible build artifacts.
